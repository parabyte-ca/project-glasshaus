# Security policy

Please report vulnerabilities privately via GitHub Security Advisories
(**Security → Report a vulnerability** on this repository). Do not open public issues for security reports.

Baseline: OWASP ASVS 4.0 Level 2. Secrets are generated by `setup.sh` into `.env` (mode 600) and are never
committed; CI runs gitleaks, pip-audit, npm audit and Trivy on every change.
